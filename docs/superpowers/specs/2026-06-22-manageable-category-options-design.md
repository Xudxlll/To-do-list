# “今天干什么”可管理选项设计

## 背景

“今天干什么”当前由代码内默认选项、云端自定义选项和本地排序共同组成。默认选项不能编辑或删除，自定义选项只能追加到“其他”，排序也只保存在本机，无法满足双人共同维护选项库的需求。

本次改造把所有选项统一成可管理内容，同时保持现有分类选择、分享和结果页行为。

## 目标

- 所有默认选项和新增选项都支持新增、查看、编辑、永久删除。
- 每个选项包含必填名称和选填描述。
- 描述沿用“今天去哪逛”的现有样式：名称在上、浅灰小字在下，二者属于同一个可勾选选项块。
- 每个固定子分类标题旁提供新增按钮。
- 选项支持同组拖动排序和跨子分类拖动归类，顺序同步给两位用户。
- 支持单个子分类展开或收起，并提供一键收起全部子分类。
- 支持按名称和描述搜索全部大分类。
- 云端操作失败时不留下仅本机可见的临时状态。

## 非目标

- 不新增、删除、改名或排序子分类。
- 不提供删除项回收站或恢复默认选项入口。
- 不追溯修改已经发送出去的历史分享内容。
- 不改变大分类的数量、名称或排序。

## 已确认的产品决策

- 默认项和新增项一视同仁，全部可改可删。
- 删除是永久操作；重新需要同名内容时，用户手动新增为新的选项。
- 管理操作采用独立“管理模式”，普通模式保持清爽。
- 拖动可以跨子分类，跨组移动同时完成重新归类。
- 描述可选；没有描述时只显示名称，不预留描述空白。
- 子分类保持固定，但可以单独折叠；“全部收起”只展示子分类标题。
- 搜索覆盖全部大分类，并同时匹配名称和描述。

## 数据架构

### 总体方案

采用“代码默认数据 + 云端覆盖层”。`miniprogram/data/categories.ts` 继续提供完整基础数据，云端记录用户对基础数据的覆盖以及所有新增数据。页面加载时合并两者，得到最终选项树。

该方案不要求首次发布时批量写入全部默认数据。即使云端暂时不可用，仍可使用代码默认数据和最近一次成功缓存。

### 稳定标识

- 现有默认选项 ID 继续作为稳定 `optionId`，不能因改名或移动子分类而改变。
- 新增选项使用随机且稳定的 `optionId`，不再根据名称生成 ID。
- 改名、修改描述、移动分组和排序都只更新属性，不替换 `optionId`。
- 同一大分类内的有效选项名称必须唯一；已删除项不参与重名校验。

### 云端记录

继续使用 `custom_options` 集合，但扩展为两类记录。

选项覆盖记录：

```ts
interface ManagedOptionRecord {
  _id?: string;
  recordType: 'option';
  optionId: string;
  categoryId: string;
  groupId: string;
  source: 'preset' | 'custom';
  name: string;
  normalizedName: string;
  description: string;
  deleted: boolean;
  createdAt: number;
  updatedAt: number;
}
```

分组排序记录：

```ts
interface GroupOrderRecord {
  _id?: string;
  recordType: 'group_order';
  categoryId: string;
  groupId: string;
  optionIds: string[];
  updatedAt: number;
}
```

选项记录只在默认值被修改、移动或删除时创建；新增选项从创建起就拥有完整记录。排序记录保存每个固定子分类当前的完整有效顺序。两人同时修改时采用最后一次成功写入为准，符合当前双人低并发场景。

### 删除语义

- 删除默认项时写入 `deleted: true` 的覆盖记录，阻止它从代码默认数据中再次出现。
- 删除新增项时同样保留删除记录，避免旧缓存或旧版记录令其重新出现。
- 产品界面不提供恢复入口。
- 用户之后可以重新添加同名内容；它会获得新的 `optionId`。

### 旧数据兼容

- 没有 `recordType` 的旧 `custom_options` 记录继续按旧字段读取。
- 旧记录初次展示时生成兼容稳定 ID，并保留原名称。
- 当旧选项被编辑、移动或排序时，将它写成新的完整选项记录；旧记录不再参与最终合并。
- 云端读取必须处理集合分页，不能依赖单次查询覆盖全部选项。

### 本地缓存

- 最近一次成功合并的云端覆盖数据缓存在本地，用于快速首屏和云端失败回退。
- 现有仅本机生效的排序数据用于首次兼容；一旦云端排序成功保存，以云端排序为准。
- 折叠状态是纯界面偏好，按大分类保存在本地，不上传云端。

## 页面与交互

### 普通模式

- 顶部保留当前大分类标题，并提供搜索入口、“全部收起”和“管理”。
- 每个子分类标题可点击展开或收起，标题旁始终显示新增按钮。
- 选项继续使用现有白色选项块和左侧圆形勾选。
- 有描述时，描述以“今天去哪逛”现有 `.option-desc` 样式显示在名称下方；无描述时只显示名称。
- “全部收起”只收起当前大分类的所有子分类，不取消任何已选内容。
- 切换大分类时保留各大分类自己的折叠状态。

### 新增和编辑

- 点击子分类标题旁新增按钮，打开底部表单。
- 点击管理模式中的编辑按钮，打开同一表单并带入当前内容。
- 名称必填，去除首尾空格后长度为 1 至 30 个字符。
- 描述选填，去除首尾空格后最多 160 个字符。
- 同一大分类内不允许出现规范化后重名的有效选项。
- 表单明确显示目标子分类；编辑表单不通过下拉框改组，重新归类由拖动完成。
- 保存期间禁用重复提交。

### 管理模式

- 顶部“管理”切换为“完成”。
- 每个选项显示拖动手柄、编辑和删除操作；圆形勾选隐藏，点击选项不改变选择状态。
- 长按拖动手柄可调整同组顺序。
- 拖入另一个展开的子分类可完成跨组移动；目标子分类显示明确的接收高亮。
- 折叠的子分类可作为拖动目标，悬停后自动展开，便于跨组归类。
- 删除前显示选项名称并二次确认。删除成功后从当前选中内容中移除。

### 全局搜索

- 搜索覆盖所有大分类中的最终有效选项，匹配规范化后的名称和描述。
- 每条结果显示名称、原有描述以及“大分类 · 子分类”来源。
- 已删除选项不进入结果。
- 点击搜索结果后选中该选项，切换到对应大分类，展开对应子分类并滚动定位该项。
- 搜索为空时回到原有分类浏览状态。

## 数据流与一致性

1. 页面先读取代码默认数据与本地缓存，渲染可用首屏。
2. 页面分页拉取云端选项覆盖和排序记录。
3. 合并默认数据、旧自定义记录、新覆盖记录与排序记录。
4. 使用稳定 `optionId` 对齐本地已选内容；名称和描述更新时同步刷新当前选择。
5. 新增、编辑和删除提交后保持保存中状态；拖动时允许即时预览新位置，同时保存云端。
6. 云端成功后提交最终页面状态并更新本地缓存；失败时关闭保存中状态或恢复拖动前位置，并提示重试。

编辑已选项时保留选中状态。删除已选项时将其从本地选择中移除。分享数据是发送时快照，包含当时的名称和描述；后续编辑不修改历史分享。

## 异常处理

- 云端加载失败：显示默认数据与最近缓存，并给出非阻断提示。
- 保存失败：新增、编辑和删除不提交页面最终状态；拖动恢复原位置；任何操作都不创建本地临时共享项。
- 重复提交：保存期间锁定当前操作。
- 重名：在提交云端前本地校验，云端写入时再次按大分类和规范化名称检查。
- 旧记录异常：忽略缺少大分类或名称的无效记录，并记录警告，不阻断其他内容加载。
- 排序记录包含不存在或已删除 ID：过滤无效 ID，并把遗漏的有效选项追加到该组末尾。

## 验证策略

### 自动检查

- 默认数据、旧自定义项、编辑覆盖和删除记录合并正确。
- 新增、编辑、删除的名称、描述、分组和稳定 ID 正确。
- 空名称、重复名称和长度边界被拦截。
- 同组移动与跨组移动后，两组顺序和 `groupId` 正确。
- 删除项不会被排序记录、本地缓存或旧记录重新带回。
- 改名后保持选中；删除后移除选中；分享保留描述。
- 单组折叠和全部收起不改变已选数据。
- 全局搜索同时匹配名称与描述，过滤删除项并返回分类来源。
- 云端失败时状态可以回滚。

### 手动检查

- 微信开发者工具中验证新增、编辑、删除确认和表单输入体验。
- 验证短描述、长描述换行和无描述三种选项外观与“今天去哪逛”一致。
- 验证普通模式与管理模式切换不会误选选项。
- 验证拖动跨越滚动区域、拖入折叠子分类和目标高亮。
- 用两位体验成员验证新增、编辑、删除和排序的双端同步。
- 验证全局搜索定位、分类切换、自动展开和滚动位置。

### 回归检查

- 分类选择数量和底部发送按钮。
- 分享入口、结果页和 Perfect 锁定流程。
- 现有分类选项、分享数据和安全检查脚本。
- 日记编辑、日记首页和日记草稿相关功能。

## 验收标准

- 任意默认或新增选项都可修改名称和描述，并在另一位用户设备上看到相同结果。
- 任意选项可永久删除，重新进入页面或换设备后不再出现。
- 任意选项可在同组排序或拖到其他固定子分类，刷新后顺序与归类保持一致。
- 每个子分类可单独折叠，一键全部收起后只显示所有子分类标题。
- 全局搜索可以通过名称或描述找到选项，并定位到所属分类。
- 所有描述均按当前“今天去哪逛”的名称下方浅色小字样式展示。
- 云端失败不会产生只在本机存在的共享选项或错误顺序。
